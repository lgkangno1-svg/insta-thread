# Windows smoke test

1. Start `AVOCADOSS-Downloader.exe`.
2. Paste a public URL from each supported platform: YouTube, Instagram, Threads, Douyin, Xiaohongshu/RedNote.
3. Confirm the detected platform label is correct.
4. Click `링크 분석` and confirm at least one media option appears for valid public posts.
5. Select an item and a writable folder, then click `선택 항목 다운로드`.
6. Confirm the file exists, is non-empty, and duplicate downloads use `(2)`, `(3)`, etc.
7. Confirm invalid/private/removed links return a clear error and do not create a partial file.
