# AVOCADOSS Downloader Windows

웹사이트에서 검증된 다운로드 API를 그대로 사용하는 광고 없는 Windows 실행 파일입니다.

지원: YouTube, Instagram/Reels, Threads, Douyin/도우인, Xiaohongshu/샤오홍슈/RedNote.

## 사용법

1. 공개 게시물 링크 또는 공유 문구를 붙여넣습니다.
2. `링크 분석`을 누릅니다.
3. 원하는 영상/이미지/화질 항목을 선택합니다.
4. 저장 폴더를 선택하고 다운로드합니다.

다운로드는 `.part` 임시 파일에 먼저 기록한 뒤 완전히 수신된 경우에만 최종 파일명으로 바뀝니다. 저장 완료 후 파일 또는 폴더를 바로 열 수 있습니다.

## 업데이트

앱은 시작 후 또는 `업데이트 확인` 버튼으로 `lgkangno1-svg/insta-thread`의 공식 `desktop-v*` GitHub Release만 확인합니다. 새 EXE와 함께 게시된 SHA-256 값을 검증한 뒤에만 업데이트 설치를 제안하며, 사용자가 동의해야 현재 EXE를 교체합니다.

광고, AdSense, 브라우저 쿠키 읽기, 로그인 정보 수집은 없습니다. 사용자가 입력한 공개 URL만 AVOCADOSS 서버로 전송하여 분석 및 임시 파일 준비를 수행합니다.
