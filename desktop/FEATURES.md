# Desktop feature scope

- Paste a URL or full copied share text.
- Automatically extract and detect YouTube, Instagram, Threads, Douyin, and Xiaohongshu/RedNote links.
- Analyze through the production AVOCADOSS API.
- Show all returned video/image/archive choices including format, dimensions, and known size.
- Choose a Windows download folder.
- Queue the existing server-side preparation job and poll until ready.
- Stream the prepared file to disk without loading the complete file into memory.
- Preserve server filenames, sanitize Windows-invalid characters, and avoid overwriting existing files.
- Show network, rate-limit, invalid-link, preparation, and disk-write errors in the GUI.
- No ads, AdSense, browser cookies, login scraping, or private-media bypass.
