# Third-party references and dependencies

This project is designed around the upstream `yt-dlp` Python package and FFmpeg.

Research references include:

- yt-dlp/yt-dlp — Unlicense for source/wheel; see upstream third-party license notes.
- tribixbite/yt-dlp-threads — Unlicense/public domain reference for public Threads video extraction.
- corvardt/nostos — MIT reference for provider architecture and Threads image/video page-payload parsing.
- jiji262/douyin-downloader — MIT reference for robust Douyin fallback patterns.
- SqlCoop/OpenCLI — Apache-2.0 reference for Xiaohongshu browser-session extraction patterns.

No third-party repository is vendored wholesale in this initial scaffold.
