Threads downloader FAQ

스레드 주소는 어디에 붙여넣으면 되나요?

페이지 상단의 큰 입력칸에 Threads 공개 게시물 주소를 붙여넣고 Analyze link를 누르면 됩니다. 별도 탭 선택은 필요 없습니다.

Can I download Threads images as well as videos?

Yes. Public images exposed by the target post are presented as image assets. Video covers are labeled separately when available.

Does this work with threads.net links?

Supported public threads.net and threads.com post URL patterns are both recognized.

Can it access private posts?

No. The downloader is for publicly accessible post media and does not bypass authentication or private-account controls.

Do I have to switch to another page to paste an Instagram or YouTube link?

No. Every downloader page uses the same automatic URL detector. The platform-specific pages exist mainly as focused guides.
