유튜브·인스타그램·쓰레드 다운로더 자주 묻는 질문

유튜브 영상, 인스타그램 릴스, 쓰레드 영상과 사진을 저장할 때 자주 묻는 질문입니다. 이 사이트는 공개 링크에 접근 가능한 미디어만 지원하며, 비공개 접근 제한을 우회하지 않습니다.

어떤 SNS 플랫폼을 지원하나요?

유튜브 공개 영상·쇼츠, 인스타그램 릴스, 공개 쓰레드 게시물, 더우인 영상, 샤오홍슈 영상·이미지를 지원합니다.

영상 대신 썸네일도 저장할 수 있나요?

공개 원본이 제공하는 경우 썸네일·커버를 선택할 수 있습니다. 샤오홍슈 이미지 게시물은 개별 이미지나 ZIP 다운로드가 제공될 수 있습니다.

비공개 게시물도 지원하나요?

아니요. 공개 미디어만 지원하며 비공개 계정·로그인 제한·유료 콘텐츠·DRM은 우회하지 않습니다.

전에 되던 링크가 지금은 안 되는 이유는?

플랫폼의 페이지 구조·공유 링크·접근 정책이 바뀌거나 원본이 삭제되면 기존 링크도 실패할 수 있습니다.

공유 링크가 실패하면 어떻게 하나요?

원본 공개 게시물에서 공유 주소를 새로 복사해 다시 붙여넣으세요. 로그인 제한은 우회하지 않습니다.

다운로드 파일을 계속 저장하나요?

영구 파일 보관함은 제공하지 않습니다. 서버의 임시 파일은 전달 뒤 삭제됩니다.

영상 주소는 어디에 붙여넣나요?

홈페이지나 각 플랫폼별 안내 페이지 상단의 주소 입력칸에 붙여넣으세요. 플랫폼은 자동 감지됩니다.
