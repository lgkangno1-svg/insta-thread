What the Xiaohongshu parser does differently

Image-note detection

Normal image posts are recognized as image notes instead of producing a misleading “no video formats” failure.

Current inline note state

The adapter reads the public note state exposed by the page and selects xhscdn media candidates from the requested note.

Public-media boundaries

The service does not attempt to defeat private-note login walls, DRM or other access controls.

Xiaohongshu downloader FAQ

샤오홍슈 주소는 어디에 붙여넣나요?

페이지 상단의 큰 입력칸에 그대로 붙여넣습니다. 공유 주소를 복사한 뒤 Paste 버튼을 사용하거나 직접 붙여넣고 Analyze link를 누르세요.

Can this download image-only Xiaohongshu posts?

Yes. If the public note contains an image list, the analyzer exposes those images as separate choices. A nine-image note, for example, can return nine individual image options.

Why can an xhslink share URL fail later?

Short links and security tokens can expire or change. Copy a fresh public share URL first. Deleted, private or login-gated notes are not bypassed.

Does the downloader guarantee 4K or watermark removal?

No blanket quality or watermark claim is made. AVOCADOSS returns media candidates actually exposed by the public source and does not invent unsupported quality guarantees.
