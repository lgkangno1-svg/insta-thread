동영상 다운로더 자주 묻는 질문

유튜브, 인스타그램, 쓰레드의 공개 링크를 저장하기 전에 알아둘 내용을 정리했습니다.

주소는 어디에 붙여넣으면 되나요?

페이지 맨 위의 큰 URL 입력칸에 붙여넣으면 됩니다. 플랫폼을 고를 필요 없이 주소만 넣고 Analyze link를 누르면 자동 감지됩니다.

SNS 종류를 먼저 선택해야 하나요?

아니요. 링크를 붙여넣으면 자동 감지합니다. 아래의 플랫폼 이름은 상태 표시이며 직접 선택할 필요는 없습니다.

공개 링크인데도 다운로드가 안 되는 이유는?

원본 삭제, 지역 제한, 로그인 요구, 공유 주소 만료 또는 플랫폼 구조 변경 때문일 수 있습니다. 접근 제한은 우회하지 않습니다.

다운로드 파일을 서버에 보관하나요?

개인용 영구 보관함을 제공하지 않습니다. 전달을 위해 생성된 임시 파일은 처리 수명주기에 따라 삭제됩니다.

다른 사람의 저작권 있는 영상을 저장해도 되나요?

직접 소유하거나 적법하게 저장할 권한이 있는 콘텐츠에만 사용하세요. 각 플랫폼의 상표는 해당 권리자에게 있습니다.

광고를 클릭해야 다운로드할 수 있나요?

아니요. 광고가 있더라도 다운로드와 분리되어 있으며 광고 클릭을 요구하지 않습니다.

유튜브 다운로더와 인스타그램 다운로더를 따로 설치해야 하나요?

아니요. AVOCADOSS는 웹브라우저에서 사용하는 도구이며, 유튜브 다운로드, 인스타그램 릴스 저장, 쓰레드 다운로드를 같은 입력창에서 처리합니다. 공개적으로 접근 가능한 링크만 지원합니다.

쓰레드 영상과 사진을 둘 다 다운로드할 수 있나요?

공개 Threads 게시물이 영상이나 이미지를 제공하면 분석 결과에 해당 미디어가 따로 표시됩니다. 게시물 삭제나 접근 제한이 있는 경우에는 이용할 수 없습니다.
